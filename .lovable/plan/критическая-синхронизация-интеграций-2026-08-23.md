# Критическая синхронизация интеграций

## Изменения
- Полностью удалить оставшийся каталог `src/integrations/supabase` и проверить отсутствие пакета и импортов Supabase в исходниках и lock-файле.
- Проверить единый почтовый путь: оставить только Resend SDK через HTTPS, ключ `RESEND_API_KEY` и фиксированный sandbox-адрес `onboarding@resend.dev`; убрать устаревшие упоминания SMTP/Nodemailer.
- Закрыть прямой выход к OpenAI: для режима OpenAI обязательно брать базовый URL из `OPENAI_BASE_URL` и использовать его для обоих сценариев — конфигуратора и сканера. При отсутствии URL возвращать контролируемую ошибку вместо обращения к `api.openai.com`.
- Запустить проверку типов, поиск запрещённых упоминаний и проверку ответа приложения.

## Технические детали
- Существующий единый AI-адаптер использует HTTP `fetch`, а не OpenAI SDK. Эквивалент параметра `baseURL` уже централизован в нём; будет убран небезопасный прямой fallback, чтобы каждый OpenAI-запрос гарантированно маршрутизировался через `process.env.OPENAI_BASE_URL`.
- Коммиты выполняются платформой автоматически; состояние Git вручную изменяться не будет.
